# تطبيق زاد المسلم — تحميل النسخ

مستودع عام لتحميل تطبيق **زاد المسلم** مباشرة على الهاتف، بدون Google Play.

## 📥 تحميل أحدث نسخة

**الرابط المباشر (اضغطه من هاتفك):**

```
https://github.com/abdeladhemalshwehdi/zad-almuslim-releases/releases/latest/download/ZadAlmuslim.apk
```

أو افتح صفحة الإصدارات واختر أحدث نسخة:
👉 **https://github.com/abdeladhemalshwehdi/zad-almuslim-releases/releases**

## 📲 خطوات التثبيت على الهاتف

1. افتح الرابط من **المتصفح في هاتفك** (أو انسخه وألصقه).
2. اضغط على اسم ملف الـ `.apk` ليبدأ التحميل.
3. بعد انتهاء التحميل افتح الإشعار **"تم التنزيل"** → **تثبيت**.
4. إن ظهر تنبيه أمان: **إعدادات ← تطبيقات غير معروفة ← السماح لمتصفحك/إدارة الملفات بتثبيت التطبيقات** ← ثم أعد التثبيت.
5. إن كانت لديك نسخة سابقة من التطبيق، سيعرض النظام زر **"تحديث"** بدل "تثبيت" — **تبقى كل بياناتك وإعداداتك محفوظة**.

- مساحة تقريبية: 110 ميغابايت.
